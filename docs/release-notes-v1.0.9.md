# DayLens v1.0.9（每日镜）

本地优先的 Windows 个人电脑活动复盘工具：自动记录前台软件使用时长、文件变化、浏览器访问、软件安装与微信接收文件，合并成「今天做了什么」，并生成全天时间线、专注度评分、快照对比与 AI 中文复盘。

## 本次更新

- 设置页改为顶部横向分类，并新增包含作者及项目主页的「关于」页面
- 时间线新增指针中心缩放、左右拖动、15 分钟精细网格和精确到秒的活动提示；双击可恢复全天
- 修复连续运行跨午夜后日期不自动切换的问题，并补充跨天自动快照检查
- 修复 Chrome/Edge 正在运行时 History 被锁定导致网页浏览为空的问题，改用安全副本实时读取访问明细
- 修复大数据库下点击设置、日期或标签页需要等待的问题；日期查询由扫描百万级记录改为读取独立日期目录
- 删除启动阶段的全库 quick_check，数据库初始化实测由约 3 秒降低到约 12 毫秒
- 自动刷新增加 60 秒缓存和请求合并
- 主界面最多渲染 200 个语义活动、微信列表最多渲染 500 条，完整数据保留在 SQLite
- 新增自绘中文日期选择器、记录日期蓝点和键盘导航，并默认启用 GDI 字体渲染
- 文件监控增加目录白名单、扩展名白名单、缓存黑名单和大量变更节流
- 快照对比强制「左旧右新」，筛选、删除和 AI 解读继续保留
- 微信 `.dat` 文件通过文件头识别图片、媒体、压缩包和 PDF
- 新增全局搜索和快速速记；速记可进入当天 AI 总结上下文
- 数据库增加日期索引，避免在启动阶段同步回填百万级旧记录

## 使用说明

1. 解压后保留完整文件夹，双击 `DayLens_v1.0.9.exe`（不要单独复制 EXE，也不要移动 `_internal` 目录）
2. 首次启动会创建本地配置和数据库，并开始记录此后的活动
3. 关闭主窗口后程序继续驻留系统托盘；右键托盘图标选择「退出」才会完全关闭

若 Windows SmartScreen 提示「Windows 已保护你的电脑」，确认来源后点击「更多信息 → 仍要运行」。

## 隐私

不截屏、不录音、不记录键盘输入、不读取微信聊天内容。所有数据默认保存在本机（`%APPDATA%\DayLens`）；只有主动生成总结时，才向用户自己配置的 AI 地址发送预聚合摘要。
